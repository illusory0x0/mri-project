"AI native".

- https://projectured.org/

  - [Implementing Factorial in Common Lisp](https://www.youtube.com/watch?v=iR2cIF51SVk)

## MoonBit AI toolchain

A compiler toolchain that exposes language-aware operations to an agent through
a CLI.

- https://www.moonbitlang.com/
- `moon ide` provides `moon-lsp` functionality as a CLI for AI:
  `moon ide peek-def`, `moon ide find-references`, `moon ide rename`,
  `moon ide hover`, `moon ide outline`, `moon ide analyze`, `moon ide doc`,
  `moon ide workspace-symbols`
- Related commands: `moon check` (syntax), `moon prove` (formal verification),
  `moon fmt` (format), `moon explain` (compiler diagnostics)
